Evolución de la web

Doce momentos importantes desde los inicios de la web hasta hoy.

  1. 1989

    Propuesta de la World Wide Web

    Tim Berners-Lee, en el CERN, propone un sistema de documentos enlazados por hipertexto.

  2. 1991

    Primer sitio web público

    Se publica la primera página web, que explicaba qué era la World Wide Web.

  3. 1993

    Web libre y primer navegador gráfico

    Aparece uno de los primeros navegadores con imágenes, y el CERN libera la tecnología web al público.

  4. 1994

    Fundación del W3C

    Se funda el World Wide Web Consortium para crear estándares web.

  5. 1995

    Llega JavaScript

    Brendan Eich crea JavaScript, que da interactividad a las páginas.

  6. 1996

    CSS 1

    Se publica la primera versión de CSS para separar el contenido del diseño.

  7. 1998

    Nace Google

    El buscador cambia la forma de encontrar información en la web.

  8. 2004

    Web 2.0 y redes sociales

    Se popularizan los sitios donde los usuarios crean contenido, como Facebook.

  9. 2007

    Web móvil

    Con el iPhone, la navegación desde teléfonos inteligentes se vuelve masiva.

  10. 2014

    HTML5

    HTML5 se convierte en recomendación oficial, con audio, video y más.

  11. 2020

    Web moderna y apps web

    Aplicaciones web progresivas (PWA), frameworks y servicios en la nube.

  12. 2022

    Web con inteligencia artificial

    Los asistentes de IA se integran en sitios, buscadores y herramientas de desarrollo.
